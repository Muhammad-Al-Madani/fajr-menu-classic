# Fajr Coffee & Breakfast — электронное меню

Вариант 1 «Как у вас»: оформление по мотивам печатного меню кафе
(Учкекен, ул. Ленина, 89А).

- светлая тема при запуске, переключение на тёмную;
- русский, английский и арабский — выбирается по языку телефона, можно сменить;
- «Мой заказ»: гость отмечает блюда, видит итог и показывает список официанту;
- блюда на вес (мангал) — выбор веса шагом 100 г с расчётом суммы;
- без сервера: обычные HTML, CSS и JavaScript.

## Как поменять цены и блюда

Всё меню — в одном файле `data/menu.js`. Цена у позиции — поле `price`,
у вариантов («с курицей / с говядиной») — `price` внутри `variants`.

## Посмотреть у себя

Открыть `index.html` через любой локальный веб-сервер.
